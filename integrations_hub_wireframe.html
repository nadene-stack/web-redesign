Microsoft Project sits in Migrate in Minutes rather than the integrations grid, since importing an MPP file is a one-time migration action, not an ongoing sync like Trello or Slack. TeamGantt API gets its own spotlight rather than a grid card, matching the more elevated treatment it needs relative to same-size cards like Dropbox or Zapier. Two links are confirmed real: Excel's points to a verified CSV import article, and MS Project's is a real support link. Primavera P6's link is a placeholder marked "link needed" rather than a guessed URL, since no real support article could be confirmed for it. Calendar Feed is a two-tier subsection — a header (name and description, no icon) followed by three small calendar-type cards, with a single "Learn more" link below them. That structure makes clear this is one integration with three compatible destinations, not three separate integrations — one link, not three, since it's one support article covering all three. The green CTA button on Migrate in Minutes matches the color used in the real component; the exact hex isn't confirmed against brand guidelines. This page's version of Migrate in Minutes has no "Import your first project" button — the Prefooter CTA below it carries the page's one primary ask instead, so Migrate reads here as reassurance ("yes, your existing files come over easily") rather than a second competing conversion point. Two components on this page — API Spotlight and Migrate in Minutes — aren't in the component taxonomy yet; both are real, existing patterns worth adding to the list rather than treating as one-offs.
